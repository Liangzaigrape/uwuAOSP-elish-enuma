## 压缩包内包含

解压 `uwu_elish-17.0.181-elish-20261105.zip` 后得到：

| 文件 | 说明 |
|---|---|
| `super.img` / `boot.img` / `boot_root_apatch.img` / `vendor_boot.img` / `dtbo.img` / `vbmeta*.img` | 分区镜像 |
| `flash.bat` / `README.txt` | 刷机脚本与说明 |
| `APatch_11282_e8e4651_main-release-signed.apk` | **APatch root 管理器**，配合 `boot_root_apatch.img` 使用 |
| `相机_9.2.113.585804376.14.apk` | **谷歌相机（GCam）**，安装后即可使用 |

> 选择 root 时脚本会刷入 `boot_root_apatch.img`，开机后安装压缩包内的 APatch APK
> 完成 root 授权；不 root 则刷普通 `boot.img`。谷歌相机直接安装 APK 即可。

## 版本

- Android 17 / uwuAOSP 17.0.181
- Build ID `CP2A.260605.016 release-keys`
- 安全补丁 2026-10
- SELinux Enforcing
- 内置 GMS、Play 商店、SetupWizard
- 保留第三方触控笔支持

## 刷机

1. 解锁 Bootloader，音量下 + 电源进入 fastboot
2. 所有镜像与 `flash.bat` 放同一文件夹，双击运行
3. 机型校验通过后，按提示选择是否清数据、是否 root

> MIUI / HyperOS 用户**必须清除数据**。

## 说明

- 不含 MIUI 相机（native 依赖与相机 ID 映射在 AOSP 上不完整），相机使用 Aperture
- 签名使用自建密钥，非 AOSP 公开 testkey

## 完整性

见 `checksums.sha256`，Windows 可用 `certutil -hashfile <文件> SHA256` 校验。
