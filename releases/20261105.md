## 版本

- Android 17 / uwuAOSP 17.0.181
- Build ID `CP2A.260605.016 release-keys`
- 安全补丁 2026-10
- SELinux Enforcing
- 内置 GMS、Play 商店、SetupWizard
- 保留第三方触控笔支持

## 刷机

1. 解锁 Bootloader，音量下 + 电源进入 fastboot
2. 所有镜像与 `flash.bat` 放同一文件夹，双击运行
3. 机型校验通过后，按提示选择是否清数据、是否 root

> MIUI / HyperOS 用户**必须清除数据**。

## 说明

- 不含 MIUI 相机（native 依赖与相机 ID 映射在 AOSP 上不完整），相机使用 Aperture
- 签名使用自建密钥，非 AOSP 公开 testkey

## 完整性

见 `checksums.sha256`，Windows 可用 `certutil -hashfile <文件> SHA256` 校验。
