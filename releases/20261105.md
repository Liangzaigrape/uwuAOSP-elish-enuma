## 刷机

1. 解锁 Bootloader，音量下 + 电源进入 fastboot
2. 用 `merge-parts.bat` 合并分卷，校验通过后解压
3. 解压目录里双击 `flash.bat`，按提示选择是否清数据、是否 root
4. 需要 root 时脚本刷入 `boot_root_apatch.img`，开机后安装压缩包内的 APatch APK 完成授权

> 从 MIUI / HyperOS 刷入**必须清除数据**；其他类原生系统可先不清，异常再清。
> 机型校验仅允许 `elish` / `enuma`。
